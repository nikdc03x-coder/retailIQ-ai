# Architecture and Data Flow

1. Load source CSV files.
2. Validate data quality.
3. Clean and transform records.
4. Store validated data in SQLite.
5. Calculate business metrics.
6. Train and evaluate forecasting models.
7. Detect unusual sales periods.
8. Explain predictions with SHAP.
9. Retrieve verified facts for the AI assistant.
10. Present results through Streamlit.

Notebooks are used for learning and experiments.
Python scripts contain reusable project logic.
