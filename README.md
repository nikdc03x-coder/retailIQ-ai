# RetailIQ AI

RetailIQ AI is a beginner-friendly retail sales intelligence project.

## Business Problem
Retail sales data is difficult to interpret without cleaning,
analysis and suitable forecasting methods.

## Planned Features
- Data engineering and quality checks
- Business analytics
- Sales forecasting
- Anomaly detection
- Explainable AI
- Grounded Gemini assistant

## Technology
Python, Pandas, Streamlit, Plotly, Scikit-learn,
XGBoost, SHAP, SQLite, FastAPI and Gemini.

## Start the Dashboard
1. Activate the virtual environment.
2. Install requirements.
3. Run: python -m streamlit run 11_dashboard/main.py
